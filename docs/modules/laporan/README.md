# Modul Laporan

## Overview
Modul Laporan mengelola generate dan export laporan audit dalam berbagai format (PDF/Excel).

---

## Fitur

### 1. Jenis Laporan
- Laporan Sesi Audit (per sesi)
- Laporan Temuan by Unit
- Laporan Temuan by Kategori
- Laporan RTL Progress
- Laporan Komprehensif Periode
- Laporan Statistik Audit

### 2. Format Export
- PDF (untuk laporan formal)
- Excel (untuk analisis data)

### 3. Filter & Parameter
- Periode audit
- Unit kerja
- Range tanggal
- Status RTL
