# Modul Activity Log

## Overview
Modul Activity Log untuk tracking semua aktivitas user dalam sistem (audit trail).

---

## Fitur

### 1. Auto Logging
- Track CRUD operations (Create, Read, Update, Delete)
- Track login/logout
- Track status changes (RTL, Sesi)
- Track file uploads/downloads
- Track approval/reject actions

### 2. View Logs
- Admin: View all logs
- User: View own activity history
- Filter by: user, action, module, date range

### 3. Log Details
- Timestamp
- User (who)
- Action (what)
- Resource (entity + ID)
- Changes (before/after values)
- IP Address
- User Agent
