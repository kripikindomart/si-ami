# Modul Dashboard

## Overview
Modul Dashboard menampilkan statistik dan insight dari data audit dalam bentuk visualisasi dan ringkasan.

---

## Fitur

### 1. Dashboard Admin GPM
- Overview statistik periode aktif
- Chart: Temuan by kategori, Temuan by unit
- Chart: RTL status distribution
- Timeline audit schedule
- Alert: Deadline RTL mendekat/overdue

### 2. Dashboard Auditor
- My upcoming sesi
- My completed sesi count
- Quick action: Input temuan/nilai positif

### 3. Dashboard PIC Unit
- Unit audit status
- Temuan list for my unit
- RTL status & deadline
- Alert: RTL overdue
